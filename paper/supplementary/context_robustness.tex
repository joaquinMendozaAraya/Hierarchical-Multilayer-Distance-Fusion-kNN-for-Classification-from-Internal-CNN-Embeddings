\section*{Supplementary Context-Level Robustness}

The main paper reports aggregate performance and retains the context-level
analysis as a robustness check. Within each dataset-backbone context, the
non-proposed reference method was selected by validation macro-F1 before the
frozen test comparison. Table~\ref{tab:dataset_summary} summarizes absolute
macro-F1 by dataset, while Table~\ref{tab:context_outcomes} separates
numerical, practical, and paired statistical interpretations.
